# Test Case 01 ILT Z Branch Valve

Accepted paper test case package for the ILT-Z branch valve layout trial.

## Contents

- `TEST_CASE_01_ILT_Z_BRANCH_VALVE_REPORT.docx` - Word report with tables and embedded plot.
- `TEST_CASE_01_LAYOUT.png` - deterministic plot output.
- `layout.json` - EDAS-compatible concept layout input used for plotting.
- `plot_report.json` - plotter QA and governance report.
- `layout.parameters.csv` - parameter sidecar exported by the plotter.

## Review status

Human review accepted branch valve placement, connection labels, and high-strain marker location. The record remains a concept-level paper test case, not a final engineering design claim.

## Future study note

Branch pipe geometry may affect peak header strain and strain location. The related future study candidate is recorded at `knowledge/edikb/future_study_candidates/BRANCH_GEOMETRY_STRAIN_COVARIANCE_ILT_Z_01.json`.
