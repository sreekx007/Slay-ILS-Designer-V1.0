# Test Case 02: Inline valve protected by fitted GD-SB base

This folder records the accepted second worked example for Paper 01A Section 9.

The case covers a 20 inch inline header valve that cannot contact or take reaction from the stinger. The accepted layout uses a fitted GD-SB base structure, explicit GD-TP connector landing bodies, and GD-Con P-S support connectors.

The conversation-style record is in `TEST_CASE_02_CONVERSATION_RECORD.md`.
